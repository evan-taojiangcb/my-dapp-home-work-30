## 1. 需求概述

对已完成的 Solana Phantom 钱包连接功能进行以下 UI/UX 增强：

1. 将钱包连接按钮移至顶部 Header，水平横向布局
2. 网络选择支持 Solana Devnet 和 Ethereum Sepolia，可切换，联动显示对应币种余额
3. 地址/网络/币种信息使用圆角底色样式（与 WalletInfoPanel 一致）
4. 钱包内操作（切换账号/网络/余额变动）实时同步到页面

### FR-002: 网络选择器 — 双链支持

**描述**: 添加网络选择器组件，支持 Solana Devnet 和 Ethereum Sepolia 切换。

**网络配置**:

| 链 | RPC Endpoint | 币种 | 钱包 |
|----|-------------|------|------|
| Solana Devnet | `https://api.devnet.solana.com` | SOL | Phantom |
| Ethereum Sepolia | `https://rpc.sepolia.org` 或 Alchemy/Infura | ETH | Phantom（ETH）或 MetaMask |

**架构决策**: 由于 Phantom 主要用于 Solana，Ethereum Sepolia 需额外接入 Ethereum 钱包（本迭代先只做 Solana 双网络切换的 UI 框架，Ethereum 钱包接入为后续迭代预留）。

**本迭代范围**: 网络选择器 UI + Solana 网络切换（Devnet ↔ 主网候选），Sepolia 切换仅做 UI 占位 + 提示"需安装 Ethereum 钱包"。

**验收标准**:
- [ ] `NetworkSelector` 组件显示当前网络名称
- [ ] 点击后下拉显示可用网络列表（至少 Solana Devnet + Sepolia placeholder）
- [ ] 切换 Solana 网络后，余额显示联动更新为对应币种（SOL）
- [ ] Sepolia 选项点击后显示提示"请安装 Ethereum 钱包"

### FR-004: 钱包操作实时同步

**描述**: 当用户在钱包内进行操作（切换账号、切换网络、余额变动）时，页面 UI 实时响应。

**Solana 链内同步**:

| 事件 | UI 响应 |
|------|---------|
| 切换账号 | `WalletInfoPanel` 地址立即更新为新公钥的 Base58 |
| 切换网络 | 网络显示文本立即更新（如有多个 Solana 网络选项） |
| 余额变动 | `useSolanaBalance` 的 React Query 自动重新 fetch，UI 显示新余额 |

**技术实现**: `useWallet()` 的 `publicKey` 是响应式的——Phantom 切换账号后，`useWallet().publicKey` 自动变更为新值，React 重新渲染。`useSolanaBalance` 依赖 `publicKey` 作为 query key，key 变化自动触发新查询。

**验收标准**:
- [ ] Phantom 中切换账号后，页面地址显示立即变化（无刷新）
- [ ] `WalletInfoPanel` 余额在 30 秒内自动刷新（staleTime）
- [ ] 手动触发刷新：余额显示支持点击刷新
