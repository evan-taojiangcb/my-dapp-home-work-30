## 需求描述

在 Web 前端（`apps/web`）集成 Solana Phantom 钱包，实现以下功能：

1. **连接 Phantom 钱包** — 用户点击按钮后弹出 Phantom 钱包连接
2. **显示钱包信息** — 连接成功后展示：钱包地址、网络、余额
3. **断开连接** — 支持断开已连接的钱包

---

## 功能性需求

### FR-001: 钱包连接

- 使用 `@solana/wallet-adapter-react` + `@solana/wallet-adapter-react-ui`
- 支持 `PhantomWalletAdapter`
- 连接网络固定为 **Solana Devnet**（`https://api.devnet.solana.com`）
- `autoConnect` 开启，首次打开页面自动重连上次钱包

### FR-002: 钱包信息展示面板

连接成功后显示以下信息：

| 字段 | 说明 |
|------|------|
| 钱包地址 | Base58 格式，前 4 位 + "..." + 后 4 位（可点击复制完整地址） |
| 网络 | 显示 "Solana Devnet" |
| SOL 余额 | 从链上获取，展示 4 位小数（如 `1.2345 SOL`） |

### FR-003: UI 组件

- 使用 `WalletMultiButton` 作为连接触发按钮
- 钱包信息展示使用独立卡片组件
- 断连按钮（使用 `useWallet` 的 `disconnect`）
- 连接状态：未连接 / 连接中 / 已连接（不同 UI 状态）
- 余额加载中状态（skeleton 或 spinner）

### FR-004: 余额查询实现

- 使用 `@solana/web3.js` 的 `Connection` + `getBalance()`
- 余额实时刷新（连接时拉取一次即可，不做定时轮询）
- 余额查询失败时展示 "— SOL"，不崩溃

---

## 非功能性需求

### NFR-001: SSR 兼容

- Wallet Provider 必须仅在客户端加载（`"use client"`）
- Next.js App Router 下需处理好 context 复用问题

### NFR-002: 错误处理

- Phantom 未安装时，`WalletMultiButton` 自动处理（显示安装提示）
- 网络请求失败时优雅降级，不影响 UI

### NFR-003: 依赖

已有依赖（**无需重新安装**）：
```
@solana/wallet-adapter-phantom
@solana/wallet-adapter-react
@solana/wallet-adapter-react-ui
@solana/web3.js
```

## 参考技术方案

用户提供的 Wallet Adapter 方案（生产级）：

```tsx
// Provider 初始化
<ConnectionProvider endpoint="https://api.devnet.solana.com">
  <WalletProvider wallets={wallets} autoConnect>
    <WalletModalProvider>{children}</WalletModalProvider>
  </WalletProvider>
</ConnectionProvider>

// 连接按钮
<WalletMultiButton />

// 获取地址
const { publicKey, connected } = useWallet();

// 余额查询
const connection = new Connection(endpoint);
const balance = await connection.getBalance(publicKey);
```
